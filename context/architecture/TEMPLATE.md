# Architecture record template

Use this template for architecture decisions, component boundaries, or integration design records.

## Record structure

### <Descriptive architectural decision>

**ID: ADR-XXX**

**Status:** Proposed.

The architecture decision states the intended system boundary, component responsibility, or integration approach.

**Rationale:** Explain why this is the chosen design and what alternatives it balances.

**Constraints:** Document technology, operational, or trust-boundary limits.

**Dependencies:** Reference requirement or security records by ID when relevant.

**Verification expectation:** Describe what evidence would satisfy the intended architecture decision.

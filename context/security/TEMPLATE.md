# Security record template

Use this template for assets, threats, controls, or residual risk decisions.

## Record structure

### <Descriptive security requirement>

**ID: SEC-XXX**

**Status:** Proposed.

The security record states the intended control, trust boundary, or protection expectation.

**Rationale:** Explain the asset, threat, or operational risk being addressed.

**Constraints:** Document any hard limitations or assumptions about the deployment environment.

**Dependencies:** Reference requirement or architecture records by ID where applicable.

**Verification expectation:** State what review or testing would demonstrate the security expectation is met.

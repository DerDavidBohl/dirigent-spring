# Coding record template

Use this template for implementation standards, review rules, or maintainability expectations.

## Record structure

### <Descriptive coding standard>

**ID: COD-XXX**

**Status:** Proposed.

**Basis:** Identify the stakeholder input or upstream context records that justify this coding standard. Keep implementation-derived observations outside the normative record.

The coding record states the intended implementation convention or maintainability expectation.

**Rationale:** Explain why this standard matters to correctness, clarity, or operational safety.

**Constraints:** Document any technology or review constraints that limit the implementation choice.

**Dependencies:** Reference requirement, architecture, or quality records by ID when relevant.

**Verification expectation:** State how the standard should be validated during review or testing.

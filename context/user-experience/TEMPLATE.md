# User Experience record template

Use this template for operator journeys, interaction expectations, or accessibility requirements.

## Record structure

### <Descriptive user flow>

**ID: UX-XXX**

**Status:** Proposed.

**Basis:** Identify the stakeholder input or existing context records that justify this experience expectation. Do not infer intended UX from implementation behavior alone.

The record describes the intended user interaction or goal in plain language.

**Rationale:** Explain why the interaction matters to the user and how it supports operations.

**Constraints:** Capture any usability or access assumptions relevant to the flow.

**Dependencies:** Reference relevant requirement or architecture records by ID when needed.

**Verification expectation:** Describe the observable evidence that the user experience is met.

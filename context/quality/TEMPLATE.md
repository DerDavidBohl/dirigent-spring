# Quality record template

Use this template for measurable quality attributes, scenarios, or verification goals.

## Record structure

### <Descriptive quality attribute>

**ID: QUA-XXX**

**Status:** Proposed.

**Basis:** Identify the stakeholder input or existing context records that justify this quality goal. Do not use current implementation behavior as its normative basis.

The quality record states the intended quality target or scenario.

**Rationale:** Explain why the quality attribute matters to the system and its operators.

**Constraints:** Capture any limits or assumptions that constrain the quality goal.

**Dependencies:** Reference relevant requirement or security records by ID where needed.

**Verification expectation:** Describe how the repository should demonstrate the quality target in testing or review.
